# Space Mission Designer (playable web build)

Play it: https://a77chand.github.io/space-mission-designer/

A game for the NASA Space Apps Challenge 2026: learn how to get a spacecraft to orbit through four short puzzles (mass, power, data link, budget and time), then design, test, launch and operate a full mission. Whatever happens, the game explains why.

This repository only holds the exported web build. The source code lives in the team's private repository.

Numbers in the game are placeholders or clearly labelled illustrative values unless a source is shown in the game.
